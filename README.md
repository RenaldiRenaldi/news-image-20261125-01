# Wednesday 25 November 2026: World News

This entry is a single 1024x1024 front page covering 38 verified stories across 9 regions, with a hand-authored equirectangular world map. The lead is the reported breach of CIA and ODNI unclassified open-source intelligence systems. Co-leads cover the 490,334 registered Russian dead anchoring a modelled total over 700,000, Huawei's 10-of-12-count conviction, and the Houthi attacks on Riyadh and Ras Tanura. The Iran tanker item is explicitly labelled an IRGC claim that is not independently confirmed.

Run locally with `python3 render.py`, then use `MAKEFUN_OUTPUT_DIR=out node main.ts` to copy the finished `entry.png` into the server output directory.
