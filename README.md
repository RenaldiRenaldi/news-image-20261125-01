# Wednesday 25 November 2026: World News

This entry is a single 1024x1024 front page covering 38 verified stories across 9 regions and 18 fields. The lead is the reported breach of CIA and ODNI unclassified open-source intelligence systems. Co-leads cover the modelled estimate of more than 700,000 Russian soldiers killed, Huawei's 10-of-12-count conviction, and the Houthi drone strike on Riyadh's PIF tower. The Iran tanker item is explicitly labelled an unverified claim.

Run locally with `python3 render.py`, then use `MAKEFUN_OUTPUT_DIR=out node main.ts` to copy the finished `entry.png` into the server output directory.
